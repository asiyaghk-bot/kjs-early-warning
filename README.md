# KJS Early Warning Dashboard

A student performance and risk-tracking dashboard developed as part of my internship project.

## Overview

The KJS Early Warning Dashboard is designed to help identify students who may need academic attention by providing a centralised view of student performance, assignments, and risk indicators.

## Features

- Student performance overview
- Student risk identification
- Assignment tracking
- Performance visualisation
- Dashboard statistics
- Interactive alerts and UI components

## Technologies

- HTML
- CSS
- JavaScript

## Project Status

Currently in development.
